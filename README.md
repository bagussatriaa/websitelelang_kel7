📌 Overview

Money Trackizer adalah aplikasi manajemen keuangan pribadi berbasis Android yang membantu pengguna mencatat dan memantau kondisi keuangan secara terstruktur.

Aplikasi ini dirancang untuk memudahkan pengguna dalam:

Mengelola langganan bulanan

Mencatat pemasukan dan pengeluaran

Melihat ringkasan keuangan secara visual

Mengontrol anggaran agar pengeluaran tetap terjaga

Dengan antarmuka yang sederhana dan intuitif, aplikasi ini cocok digunakan untuk kebutuhan pengelolaan keuangan sehari-hari.

✨ Fitur Utama

Dashboard Keuangan
Menampilkan ringkasan kondisi keuangan dan langganan aktif secara visual.

Manajemen Langganan
Mencatat dan memantau langganan bulanan seperti streaming dan layanan digital.

Pemasukan & Pengeluaran
Pencatatan transaksi keuangan secara terpisah dan terstruktur.

Kalender Transaksi
Melihat histori keuangan berdasarkan tanggal.

Monitoring Anggaran
Membantu pengguna mengontrol pengeluaran agar tidak melebihi batas.

Pengaturan Aplikasi
Preferensi tema dan pengaturan aplikasi lainnya.
